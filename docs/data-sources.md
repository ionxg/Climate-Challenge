# Climate data sources

| Source | What | Key? |
|---|---|---|
| [Open-Meteo](https://open-meteo.com/) | Historical + forecast weather, air quality | No |
| [NASA POWER](https://power.larc.nasa.gov/) | Solar, temperature, wind (good for renewables) | No |
| [Our World in Data](https://github.com/owid/co2-data) | CO2 / GHG emissions by country | No |
| [NOAA CDO](https://www.ncdc.noaa.gov/cdo-web/) | Station climate records | Free token |
| [Copernicus CDS](https://cds.climate.copernicus.eu/) | ERA5 reanalysis | Free account |
| [Global Forest Watch](https://www.globalforestwatch.org/) | Deforestation / land use | Varies |
| [NIWA](https://niwa.co.nz/) / [Stats NZ](https://www.stats.govt.nz/) | NZ climate + emissions | Mostly no |
